# FG Rock Bright website

Company website for **FG Rock Bright** (supplier & contractor) — gypsum channel manufacturing, Shameerpet, Hyderabad.

## Open the site

Node is not required. Open `index.html` in a browser, or use Cursor’s Live Preview / any local static server.

Pages:

- `index.html` — home
- `products.html` — catalogue and gauges
- `manufacturing.html` — plant photos, video, lab report
- `contact.html` — map, phone, quote form (sends to WhatsApp)
